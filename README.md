# Python Developer Portfolio

Адаптивное портфолио на русском языке: HTML, CSS и JavaScript без сборки и npm.

## Возможности
- Адаптивная вёрстка для мобильных и настольных экранов
- Фильтрация 8 демонстрационных проектов
- Модальные окна с описанием проектов
- Блоки услуг, процесса работы и контактов
- Без зависимостей от backend

## Запуск локально
1. Скачайте или клонируйте репозиторий.
2. Откройте `index.html` в браузере.

Для локального сервера можно использовать Python:
```bash
python -m http.server 8000
```
Затем откройте http://localhost:8000

## Перед публикацией — обязательно настройте
Откройте `index.html` и замените:
- `https://t.me/your_username` на свою ссылку Telegram
- `https://github.com/your_username` на свой профиль GitHub
- Текст о стаже — только на подтверждённый реальный опыт
- Описание и карточки демонстрационных кейсов — на проекты, которые вы действительно реализовали, когда они будут готовы

В макете есть 8 **демонстрационных кейсов**. Не представляйте их как оплаченные клиентские проекты, отзывы или production-системы, если это не так. Чтобы превратить каждый кейс в реальный проект:
1. Реализуйте минимальную работающую версию.
2. Добавьте код в отдельный GitHub-репозиторий.
3. Напишите README: проблема, решение, стек, установка, запуск, скриншоты и ограничения.
4. Добавьте ссылку на репозиторий и короткое видео/скриншоты в портфолио.

## Публикация через GitHub Pages
1. Создайте аккаунт на https://github.com/ (если ещё нет).
2. Создайте новый публичный репозиторий, например `python-dev-portfolio`.
3. Загрузите в корень репозитория `index.html`, `styles.css`, `script.js` и `README.md`.
4. В репозитории откройте **Settings → Pages**.
5. В разделе **Build and deployment** выберите **Deploy from a branch**.
6. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
7. Подождите завершения публикации. Адрес появится в разделе Pages и обычно будет иметь вид `https://ВАШ-ЛОГИН.github.io/python-dev-portfolio/`.

Если используете специальный репозиторий `ВАШ-ЛОГИН.github.io`, сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/`.

## Как сделать портфолио сильнее
- Закрепите 3 лучших репозитория в профиле GitHub.
- Добавьте реальные скриншоты и GIF/видео работы.
- Укажите конкретные решения: тесты, обработку ошибок, структуру проекта, деплой.
- Не публикуйте токены, `.env`, пароли, персональные данные и клиентский код без разрешения.
- Не добавляйте фиктивные цифры, отзывы или названия клиентов.
